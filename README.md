# Blueberry – Gestion d'une chaîne de magasins
Blueberry est une application de gestion destinée à une chaîne de petits magasins appelée **Bleuetière**, qui regroupe plusieurs points de vente.
L'application permet de gérer les différents magasins et leurs produits à partir d'une interface centralisée.

## Fonctionnalités
### Gestion centralisée des catégories
La section « Gérer les catégories » permet d'effectuer des changements applicables à l'ensemble des magasins. Il est également possible de sélectionner un magasin pour gérer les produits qui y sont vendus.

### Gestion d'un magasin
L'utilisateur peut sélectionner un magasin et accéder à trois sections :
- **Caisse :** effectuer des transactions de vente.
- **Manager :** gérer les produits du magasin.
- **Comptabilité :** consulter les rapports de ventes.

## Technologies utilisées
- C#
- ASP.NET Core
- Blazor
- SQL Server

## État du projet
Blueberry est un projet personnel en cours de développement. De nouvelles fonctionnalités sont progressivement ajoutées et les fonctionnalités existantes continuent d'être améliorées et testées.
